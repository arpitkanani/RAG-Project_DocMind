How It Works

What is a RAG Pipeline?

RAG stands for Retrieval-Augmented Generation. Instead of the AI guessing from memory, it first finds the relevant parts of your document, then generates an answer using only that content — like giving the AI an open-book exam instead of asking it to recall from memory.

Under the Hood

Tech Stack

Every layer of the pipeline, from ingestion to serving.

Orchestration

LangChain

Document loaders, text splitters, prompt templates, and output parsing across the ingestion and QA chains.

Vector Database

Qdrant

Stores chunk embeddings per source, containerized with Docker. Powers semantic similarity search at query time.

LLM Inference

Groq

Low-latency hosted inference for answer generation and summarization.

Embeddings

Ollama · nomic-embed-text

Converts text chunks and queries into vectors for semantic search.

API Layer

FastAPI

REST endpoints for ingestion, querying, session management, and source lifecycle.

Relational Data

PostgreSQL

Multi-user session isolation, chat history with time-windowed retention, and API-key authentication.

Auth

API Key (per-user)

Every request is scoped to a verified user — one account's chats and documents are never visible to another.

Infrastructure

Docker

Qdrant, Postgres, and the app itself run as containerized services.

Video Ingestion

How YouTube Processing Works

Paste a link, DocMind does the rest — here's exactly what happens behind the scenes.

1

URL submitted

The video ID is extracted from the pasted YouTube URL.

2

Transcript fetched

The video's caption track is pulled as a series of timestamped text segments.

3

Segments merged into passages

Raw captions are short — often just a few words each. Consecutive segments are merged into ~600-character passages so each retrieval unit is a coherent thought, with a timestamp range attached (e.g. 1:15–2:03) instead of a single instant.

4

Embedded and stored

Each passage is embedded and stored in its own Qdrant collection, scoped to that video.

5

Ready to chat

Ask direct questions or request a summary — answers cite the specific timestamp range they came from.
