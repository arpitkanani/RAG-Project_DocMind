Under the Hood

Engine Architecture & Stack

Enterprise-ready asynchronous components engineered for precision and speed.

Workflow Engine

LangGraph & StateGraph

Stateful agentic routing, intent classification, tool dispatch, and checkpoint persistence.

Vector Database

Qdrant

Containerized vector index providing filtered similarity and MMR search across collection scopes.

Relational Cloud DB

Supabase PostgreSQL

Dual-pool architecture: direct connection (port 5432) for LangGraph checkpointer and transaction pooler (6543) for sessions.

LLM Inference & Fallback

Groq, Gemini & Azure OpenAI

High-speed reasoning with Groq & Gemini free tiers, backed by Azure OpenAI (gpt-5.4-nano) enterprise cloud fallback.

Authentication

API Key & Session Tokens

SHA-256 hashed API key authentication, 30-day session lifecycle, and automatic guest fallback.

API Layer
