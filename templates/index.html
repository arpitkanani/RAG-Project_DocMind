RAG Architecture

How Document Reasoning Works

DocuVortex executes an agentic Retrieval-Augmented Generation (RAG) StateGraph with strict intent routing, document relevance grading, and cited generation.

1
Knowledge Ingestion
Upload PDF, DOCX, or paste captioned YouTube URL
2
Semantic Chunking
Recursive text chunking preserving metadata and boundaries
3
Dense Embeddings
BGE or Azure OpenAI (text-embedding-3-small, 1536-dim)
4
Qdrant Vector Store
Cosine similarity & lexical overlap with collection isolation
5
LangGraph Reasoning
Multi-turn StateGraph with negative constraint verification
6
Grounded Synthesis
Grounded answer with exact page citations and video timestamps

Platform Architecture

Engine Architecture & Technology Stack

Enterprise-ready asynchronous components engineered for precision, speed, and strict verification.

Workflow Engine

LangGraph & StateGraph

Stateful agentic routing, intent classification, tool dispatch, and checkpoint persistence.

Vector Database

Qdrant

Containerized vector index providing filtered similarity and MMR search across collection scopes.

Relational Cloud DB

Supabase PostgreSQL

Dual-pool architecture: direct connection (port 5432) for LangGraph checkpointer and transaction pooler (6543) for sessions.

LLM Inference & Fallback

Groq, Gemini & Azure OpenAI

High-speed reasoning with Groq & Gemini free tiers, backed by Azure OpenAI (gpt-5.4-nano) enterprise cloud fallback.

Embeddings Layer

BGE & Azure Embeddings

Dense semantic vector indexing (text-embedding-3-small, 1536-dim) with strict per-collection consistency checks.

API Layer

FastAPI & Async SSE

High-concurrency streaming server with sub-1.2s unified workspace bootstrap and non-blocking execution.

Real-Time Sockets

WebSockets & State Machines

Bidirectional streaming for the Master Architect Onboarding Interview and customer chat runtime.

Frontend Client

Vanilla ES6 JavaScript

Zero-build, high-performance client layer ensuring instant page loads without heavy framework overhead.
