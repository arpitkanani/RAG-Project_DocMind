Under the Hood

Engine Architecture & Stack

Enterprise-ready asynchronous components engineered for precision and speed.

Workflow Engine

LangGraph & StateGraph

Stateful agentic routing, intent classification, tool dispatch, and checkpoint persistence.

Vector Database

Qdrant

Containerized vector index providing filtered similarity and MMR search across collection scopes.

Relational Cloud DB

Supabase PostgreSQL

Dual-pool architecture: direct connection (port 5432) for LangGraph checkpointer and transaction pooler (6543) for sessions.

LLM Inference

Groq & Gemini

Low-latency reasoning models powering grounded document answering and conversational tools.

Authentication

OTP & Google OAuth

Email OTP verification, Google OAuth2, 30-day session lifecycle, and registered API key support.

API Layer

FastAPI & Async SSE

High-concurrency streaming server with real-time tool execution status badges.
